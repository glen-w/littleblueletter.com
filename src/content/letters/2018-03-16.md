<div style="font-weight: normal; font-style: normal; font-size: 16px; color: rgb(85, 85, 85);"><span style="font-weight: bolder; font-style: normal; font-size: 16px;">Eyes on the Seas</span><br/>
Illegal fishing is big business, <a href="http://journals.plos.org/plosone/article?id=10.1371/journal.pone.0004570">worth</a> between $10 billion and US $23.5 billion annually. <span style='color: rgb(51, 51, 51); font-family: Roboto, "Helvetica Neue", Helvetica, Arial, sans-serif; font-size: 16px; font-style: normal; font-weight: 400;'>It is also an incredibly </span>low risk crime. Despite increasing attention on monitoring, control and surveillance (MCS), illegal fishers are almost never caught; those that are rarely face meaningful penalties. (Except in Indonesia, where a seriously badass fisheries minister is <a href="http://www.straitstimes.com/asia/se-asia/indonesia-blows-up-and-sinks-another-81-fishing-boats-for-poaching">blowing up boats</a>.)<br/>
<img src="/images/letters/inferred-2018-03-16-1-capturedecran2018-03-16a155307.png" style="font-weight: 400; font-style: normal; font-size: 16px; outline-color: rgb(248, 174, 176); color: rgb(85, 85, 85); width: 356px; max-width: 356px;display:block;float:none;clear:both;height:auto;max-width:100%;margin:0.75rem auto;" width="356"/>
<div style="font-weight: 400; font-style: normal; font-size: 16px; color: rgb(85, 85, 85); text-align: center;"><em style="font-size: 16px;">Indonesian Fisheries Minister Susi Pudjiastuti enjoying a cup of coffee and a cigarette on her paddleboard after a hard day's work blowing up illegal fishing vessels.</em></div>
<div style="text-align: left;"><br/>
A number of initiatives are now underway that seek to reverse this trend. <a href="https://fish-i-africa.org/">FISH-i Africa</a> is bringing together countries to cooperate on fisheries enforcement and <a href="https://fish-i-africa.org/what-we-do/our-impacts/">bring illegal vessels to justice</a>. They are also supplementing information from vessels' automatic identification systems (AIS), originally designed to support safe navigation, with new tools that allow them to <a href="https://fish-i-africa.org/wp-content/uploads/2018/01/Potential-Use-of-AIS-as-a-Fisheries-Monitoring-Tool-WEB.pdf">more effectively track </a>fishing activity. (AIS is far from perfect though - it is possible for vessels to "go dark", as detailed in a <a href="http://usa.oceana.org/publications/reports/avoiding-detection-global-case-studies-possible-ais-avoidance">new report</a> out this week).<br/>
<br/>
<a href="http://www.oceanmind.global/">Ocean Mind</a> is using machine learning and big data analytics to sift through tons of data (satellite observations, vessel tracking data and identity databases, fishing license information). Their algorithms pick out possible non-compliance so that analysts can investigate. Pew's <a href="http://www.pewtrusts.org/~/media/assets/2015/03/eyes-on-the-seas-brief_web.pdf">Eyes on the Seas project</a> is using the technology to develop a cost-effective monitoring and enforcement tool that will help governments, including the most resource-poor enforcement agencies, to clamp down on illegal fishing.<br/>
